# Yunzhuru

## 关于 Yunzhuru

Yunzhuru 是一个免费的**应用内运营弹窗平台**：不用改源码、不用发版，就能在你拥有或已获授权的 Android 应用里，
上线活动弹窗、公告提醒、权限发放与数据统计。

- 永久免费，全部功能开放，没有「lite 版」
- 不限应用数量、不限弹窗数量、不按展示量或设备数计费
- 手机 App随时随地改配置、看数据

---

## 弹窗系统

- 五种弹窗类型：文本、图片、自定义 HTML、版本更新、访问验证，各自独立开关
- 十三种内置风格，另有 20+ 套成品模板（极光玻璃、赛博终端、全屏海报、全息卡密、保险库……）
- 自定义 HTML 支持纯 CSS 动效，按钮用占位符自动接管，文案与颜色在后台配置
- 按钮动作：网页 / 退出 / 复制 / 加群 / 输入 / 智能，支持三按钮与自定义事件
- 触发规则：按新老用户、时段、频率、设备维度组合下发
- 支持强制显示不可取消、外部点击关闭、倒计时自动关闭、背景压暗
- 文本弹窗支持轻提示（Toast）与强提醒两种打扰级别
- 保存并发布即刻生效，客户端下次启动拉取最新配置

## 卡密系统

- 远程开关，实时生效
- 卡密数量不限，支持批量生成、批量导出、即点即复制
- 可设有效期、可用设备数、绑定设备；支持换机解绑
- 支持试用：自定义试用时长与次数
- 卡密弹窗支持原生输入框，也支持自定义 HTML 外观（全息、保险库等模板）
- 解锁状态由服务端判定，可随时吊销

## 统计系统

- 展示、点击、转化全程记录，窗口内设备去重
- 查看今日访客、历史访客、平均日活、新增访客
- 访客明细：设备、渠道包名、应用版本、时间
- 按天趋势折线，数据可导出
- 无额外流量消耗，不影响应用性能

## 应用与分组管理

- 一个账号管理任意数量的应用
- 分组：组内共享配置、卡密与数据，成员应用保留自己的 Key 与包名
- 成员权限：所有者 / 编辑 / 只读，按人分配
- 渠道（包名）识别：可为某个渠道单独配置弹窗，未配置的走默认
- 版本历史：保留最近版本，可给每一版命名、加备注，一键回滚发布

## 版本更新

- 提示新版本与更新说明，按钮直达下载页
- 版本号、文案、是否强制更新都在后台配置

## 手机端控制台

Yuninject 控制台是一款原生手机 App，和网页后台共用同一份数据。

- 应用概览：独立访客 / 今日访客 / 可用卡密 / 待办，一眼看清
- 可视化配置：弹窗类型、风格、标题正文、按钮动作，全程点选
- 卡密管理：生成、导出、查看使用情况
- 数据看板：访客趋势、动作分布、访客明细

## 安全与合规

- 下发地址与配置内容加密，常规静态查看无法还原
- 配置同时部署在多地镜像，任一节点异常自动回退
- 可完全自托管，不依赖第三方云服务
- 仅面向**你拥有或已获授权**的应用，接入前请确认已取得授权

## 常见问题

**真的完全免费吗？**
免费。不按展示量、设备数、应用数计费，核心能力全部开放。

**改配置要重新发布应用吗？**
不用。配置保存在后台，应用启动时拉取，发布后即时生效。

**会影响原应用的性能吗？**
不会。接入层以极低开销叠加，不修改原有业务逻辑；不满足触发条件时完全不参与运行。

**没有编程基础能用吗？**
能。后台全程可视化，配置、规则、数据都是点选完成。
